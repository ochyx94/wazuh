================================================================================
CARA MANUAL ADD AGENT WAZUH
================================================================================

DI MANAGER (WSL):
---------------------------------------------------------------------------

1. Masuk ke WSL
   wsl -d Ubuntu

2. Pindah ke direktori Wazuh
   cd /var/ossec/bin

3. Jalankan manage_agents
   sudo ./manage_agents

4. Pilih menu:
   [A] Add new agent

5. Isi data:
   Agent name: windows-agent
   Agent IP: any
   Agent ID: 001

6. Extract key:
   [E] Extract key for agent(s)
   Pilih agent ID: 001

7. COPY KEY yang muncul (panjang, base64)

8. Exit:
   [Q] Quit

---------------------------------------------------------------------------

DI WINDOWS (Download & Install Agent):

9. Download Agent
   - Buka browser: https://localhost:443
   - Login: admin / Y6r4ruC.l*f8eXCbgGcfr?1eOAce?yyH
   - Menu: Agents > Deploy new agent
   - Pilih: Windows
   - Download .msi installer

10. Install Agent
    - Double-click .msi
    - Klik Next > Accept > Next
    - Wazuh manager IP: 172.28.208.227
    - Port: 1514
    - Klik Next > Install

11. Import Key
    - Buka Command Prompt as Administrator
    - cd "C:\Program Files (x86)\ossec-agent"
    - manage-agents.exe -i
    - Paste KEY yang sudah di-copy
    - Konfirmasi: Y

12. Start Service
    net start ossec

13. Verifikasi
    - Buka https://localhost:443
    - Menu: Agents
    - Lihat status: Active (green)

---------------------------------------------------------------------------

COMMAND PENTING:
---------------------------------------------------------------------------

DI MANAGER (WSL):
  sudo ./manage_agents          # Add/Remove/Extract key agent
  sudo ./list_agents            # Lihat daftar agent
  sudo ./ossec-control status   # Cek status service
  sudo ./ossec-control start    # Start service
  sudo ./ossec-control stop     # Stop service

DI WINDOWS:
  manage-agents.exe -i         # Import key
  net start ossec              # Start service
  net stop ossec               # Stop service
  sc query ossec               # Cek status

---------------------------------------------------------------------------

TROUBLESHOOTING:
---------------------------------------------------------------------------

Agent tidak konek?
  1. Cek firewall Windows: allow port 1514, 1515
  2. Cek WSL: sudo ss -tlnp | grep 1514
  3. Cek agent config: C:\Program Files (x86)\ossec-agent\ossec.conf
  4. Restart agent: net stop ossec && net start ossec

Agent status "Disconnected"?
  1. Cek Wazuh Manager jalan: sudo systemctl status wazuh-manager
  2. Cek port 1514 listen: sudo ss -tlnp | grep 1514
  3. Restart Manager: sudo systemctl restart wazuh-manager

KEY hilang/tidak bisa extract?
  1. Hapus agent lama: sudo ./manage_agents > [R] Remove agent
  2. Add agent baru dan extract key lagi
