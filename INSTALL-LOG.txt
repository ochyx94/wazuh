CATATAN PERMASALAHAN
================================================================================
[Disable Auto-Update]
Ubuntu pakai apt bukan yum.
File /etc/yum.repos.d/wazuh.repo tidak ada.

Solusi yang work:
  sudo mv /etc/apt/sources.list.d/wazuh.list /etc/apt/sources.list.d/wazuh.list.bak
  sudo apt update
